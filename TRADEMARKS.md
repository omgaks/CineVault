# CineVault Name and Brand Guidelines

## Purpose

CineVault is free and open-source software. Its source code is licensed under
the GNU General Public License version 3 only.

The GPL permits people to copy, study, modify, and redistribute the software,
including modified versions, provided that they comply with the license. Those
software freedoms do not automatically make every unofficial distribution an
official CineVault release.

These guidelines are intended to help users distinguish the official
CineVault project from independent forks and modified builds.

## Project identity

The following identify the official CineVault project:

- The name **CineVault**
- The official CineVault logo and app icon
- Official store artwork, promotional graphics, and screenshots
- Official release signing keys
- Official project and distribution accounts

Unless applicable law provides otherwise, no permission is granted to use
these elements in a way that suggests an unofficial or modified build is
published, approved, sponsored, or supported by the official CineVault
project.

## Unofficial forks and redistributed builds

If you distribute a modified or independently built version, you should:

1. Use a different application name.
2. Use a different Android package identifier.
3. Use your own app icon, logo, and promotional artwork.
4. Sign the application with your own signing key.
5. Clearly state that the build is unofficial and modified.
6. Preserve copyright and GPL notices required by the software license.
7. Provide the corresponding source code as required by GPL-3.0.
8. Avoid using official CineVault accounts, listings, or release channels.

You may retain factual attribution to CineVault and links to the upstream
project.

## Unmodified redistribution

An unmodified official APK may be redistributed only with accurate
attribution and without implying that the redistributor controls or maintains
the official project. The APK must not be resigned, repackaged, bundled with
unrelated software, or represented as a different official release.

## Community contributions

Submitting a contribution does not transfer ownership of the contributor's
personal trademarks. It also does not grant a contributor ownership of, or a
general license to represent themselves through, the official CineVault
project identity.

## No effect on GPL rights

These guidelines govern project identity and source attribution. They are not
intended to limit rights granted under GPL-3.0 to the covered software code.
If any branding asset is itself required to be licensed as part of the GPL
covered work, the GPL controls that asset to the extent legally required.

## Permission

Requests for permission to publish an official-branded build, use official
artwork, or represent a distribution as endorsed by CineVault should be sent
to the project owner through the official CineVault repository.

No permission should be assumed from silence.
